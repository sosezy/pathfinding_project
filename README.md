# Проект: Визуализатор алгоритмов поиска пути

**Выполнил:** Бакшаев Антон Павлович

## Описание проекта
Данный проект представляет собой графическое приложение для пошаговой визуализации алгоритмов поиска кратчайшего пути на плотной сетке. Дизайн и логика работы анимации максимально приближены к заданному видео-референсу.

Проект реализован на чистом Python с использованием стандартной библиотеки графического интерфейса `tkinter` (паттерн MVC).

### Реализованный функционал:
1. **Алгоритмы:** Поддерживаются два популярных алгоритма поиска пути:
   * **A* (А-звёздочка)** — с использованием эвристики (Евклидово расстояние).
   * **Алгоритм Дейкстры**.
2. **Особенности логики:**
   * Движение осуществляется в **8 направлениях** (включая диагонали).
   * Динамическое построение линии пути: алгоритм в реальном времени отрисовывает маршрут от точки старта до текущей проверяемой клетки.
3. **Визуализация (по референсу):**
   * Светло-зеленый цвет (`#c8f4c8`) — рассматриваемые клетки (frontier).
   * Светло-розовый цвет (`#f2b6b6`) — уже посещенные клетки.
   * Маджента / пурпурный (`#d800d8`) — динамическая линия текущего/итогового пути.
   * Препятствия отображаются в виде мелких черных точек.
4. **Интерактивность:** Возможность генерации случайного лабиринта и загрузки карты из внешнего `.txt` файла.

## Технологический стек
* **Язык:** Python 3
* **Графика:** `tkinter` (стандартная библиотека)
* **Алгоритмы и математика:** `heapq` (очередь с приоритетом), `math`, `random`
